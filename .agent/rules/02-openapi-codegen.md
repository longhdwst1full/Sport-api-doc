# OpenAPI and code generation

- Backend DTO/controller is the source; `api/openapi/openapi.json` is the published contract.
- Every operationId is unique, verb-first camelCase and stable across compatible revisions.
- Decorated DTO properties use explicit TypeScript types and concrete Swagger response types.
- FE endpoint URLs and API DTOs are generated by Orval. Generated files are disposable and never manually edited.
- Contract-breaking changes require an explicit migration/version decision.
