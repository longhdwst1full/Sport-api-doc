# Sport Client

Next.js storefront and PWA for the sports-commerce platform.

## Local development

```bash
yarn install --frozen-lockfile
cp .env.example .env.local
yarn dev
```

## API contract

`contracts/storefront/*.yaml` is a versioned snapshot generated by the Sport API. Never
edit generated SDK files under `src/generated/api` by hand.

```bash
yarn contracts:sync
yarn generate:api
```

`contracts:sync` downloads the generated Storefront slices from the API repository.
Override `SPORT_API_CONTRACT_BASE_URL` only for a contract branch or release artifact.

## Quality gate

```bash
yarn verify
```
