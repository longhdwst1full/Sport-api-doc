# Implement an API feature

Đọc `AGENTS.md`, `.agent/skills/nestjs-module-development/SKILL.md`, và các rule liên quan. Xác nhận DoR trong `_features`, dùng GitNexus xác định flow/impact, sau đó triển khai theo controller → service/use case → repository/Prisma. Nếu đổi DB/API, tạo migration, cập nhật tài liệu/version/change log, sinh lại OpenAPI và báo consumer impact. Kết thúc bằng lint, unit, integration/e2e phù hợp, build và `detect_changes`.
